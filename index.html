Logiciel SSH — Automatisation bornes
Alternance Cartadis · Python / SSH / Automatisation
Contexte & Objectifs

Dans le cadre de mon alternance chez Cartadis, j'ai développé un logiciel permettant de se connecter en SSH sur les bornes de lavage déployées chez les clients. L'objectif était d'automatiser les tâches de maintenance (mises à jour, scripts de diagnostic) et de faciliter l'analyse des codes d'erreur remontés par les bornes sans intervention physique sur site.

Fonctionnalités
1
Connexion SSH automatisée — Interface permettant de sélectionner une borne parmi la liste des équipements et d'établir une session SSH sans saisie manuelle des identifiants.
2
Automatisation des mises à jour — Scripts d'automatisation permettant le déploiement de mises à jour firmware sur une ou plusieurs bornes simultanément.
3
Analyse des codes d'erreur — Module de lecture et d'interprétation des logs remontés par les bornes, avec classification des erreurs et suggestions de résolution.
4
Interface utilisateur — Interface graphique simple permettant aux techniciens support de lancer les opérations sans ligne de commande.
Technologies utilisées
PythonParamiko (SSH)Tkinter / GUIScripts BashAutomatisationLogs & Diagnostic
Résultats & Apports
Réduction du temps d'intervention à distance sur les bornes
Déploiement de mises à jour sans déplacement physique sur site
Identification et résolution plus rapide des pannes grâce à l'analyse automatisée des logs
Compétences B2.1, B2.3 et B3.1 validées
Infrastructure Proxmox — Épreuve E6
Projet E6 · Proxmox / Windows Server / Debian / Zabbix / TrueNAS / Nextcloud
Contexte & Objectifs

Mise en place d'une infrastructure de virtualisation complète sous Proxmox VE dans le cadre de l'épreuve E6. L'objectif était de déployer un environnement multi-services hébergeant des VMs Windows Server, des serveurs Debian, et des solutions métier telles que Zabbix pour la supervision, TrueNAS pour le stockage et Nextcloud pour le cloud privé.

Machines déployées
1
Hyperviseur Proxmox VE — Installation et configuration de Proxmox, réseau VLAN, stockage ZFS, gestion des snapshots et sauvegardes.
2
Windows Server — VM Windows Server pour Active Directory, DNS, DHCP et gestion des utilisateurs du domaine.
3
Serveur Debian — Serveur Linux pour hébergement web, services réseau et tests de configuration.
4
Zabbix — Plateforme de supervision réseau et système : monitoring des VMs, alertes CPU/RAM/disque, tableaux de bord.
5
TrueNAS — Serveur NAS pour le stockage centralisé des données avec partages SMB/NFS et snapshots ZFS.
6
Nextcloud — Solution de cloud privé auto-hébergé pour le partage de fichiers, agenda et collaboration.
